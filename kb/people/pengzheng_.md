## Copy this in Grok Bot
1. Give every bot one narrow job.
2. Connect Figma MCP and write a skill describing your file structure, colors, type and spacing; build the system and one keyframe yourself, ask the bot to extend the rest.
3. Set up a self-updating personal site bot: send it a photo, let it publish after you approve.
4. Add a chief-of-staff bot connected to Notion.
