- Parallel coding agents in git worktrees: per-worktree setup for node_modules, .env, husky; harness-managed vs agent-made worktrees — [primer](https://davidgomes.com/worktrees-coding-agents/) (2026-08-28)

## Copy this in Grok Bot
1. For big migrations, tell your bot: use ~8 parallel workers, resumable progress files and idempotent scripts, and fall back to the browser if a connector fails.
2. Enter tokens only as masked secrets.
3. Ask the bot to self-check counts at the end (it found 195 missing cards).
4. State edge-case handling (checklists, completion dates) up front.
